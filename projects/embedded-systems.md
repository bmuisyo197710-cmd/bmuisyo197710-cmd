# Embedded systems & control engineering

## Arduino balance-control system
University of Leeds MECH1010 coursework (2023). Developed feedback-control logic for a two-motor balancing platform, using angle sensing, PID-style control, motor commands, LED indicators and serial monitoring. Academic development and simulation work, not a production controller.

## Sensor measurement simulations
Arduino instrumentation exercises covering multi-sensor acquisition, servo sweep logic, threshold detection, event counting and timing calculations. A pendulum exercise used Hall-effect sensing and peak detection to estimate oscillation periods for gravity estimation. A rotary encoder exercise used interrupt-based motion detection and Wokwi simulation.

## Ultrasonic train control lab
Academic prototype using an HC-SR04 ultrasonic sensor, pulse-duration acquisition, status indicators and serial debugging as the basis for a train-control exercise.
